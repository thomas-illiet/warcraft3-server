# Security policy

Security fixes are provided for the latest published release and the current `main` branch.

Do not open a public issue for a vulnerability. Report it privately through [GitHub Security Advisories](https://github.com/thomas-illiet/warcraft3-server/security/advisories/new) with:

- the affected version or commit;
- the deployment format and configuration involved;
- reproduction steps or a proof of concept;
- the expected impact;
- any suggested mitigation.

Avoid including real credentials, account databases, private addresses or proprietary Blizzard files. You will receive acknowledgement as soon as the report has been reviewed. Please allow time for a fix and coordinated disclosure.

Upstream vulnerabilities in PvPGN or W3L may also need coordination with their respective maintainers. This project will update its pinned source commit only after the change has been reviewed and tested.
